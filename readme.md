# 📈 Stock Market Research Projects Repository

This repository contains **two research projects** conducted in the **stock market analytics domain**, focusing on **numerical stock prediction** and **cross-market sentiment analysis**. Both projects use real-world stock-related datasets and are documented through research papers and presentation slides.

> 📌 **Note:** Detailed explanation of these research works are available in **Report**  as 2 cases studies.

---

## 🔬 Research Projects Overview

### **Case 1: Numeric Stock Price Prediction**

- Focuses on **time-series based numerical stock prediction** using historical market data
- Uses engineered financial indicators such as returns, volatility, momentum, and moving averages
- Explores **hybrid deep learning models** for improved prediction accuracy
- Includes explainability to interpret model decisions



---

### **Case 2: Cross-Market Sentiment Analysis for Stock Prediction**

- Studies the impact of **financial news sentiment** on stock movements across markets
- Uses **NLP and Transformer-based models (FinBERT)** for sentiment classification
- Performs cross-market analysis linking sentiment signals with stock behavior
- Evaluates sentiment-aware prediction performance

## 📊 Datasets

- Stock market data collected using **YFinance API**
- Covers **Indian and US markets** 
- Includes numerical features (price, volume, indicators)
- Sentiment datasets derived from financial news text using **GDELT 2.0**

---

## 🧠 Key Techniques Used

- Time-Series Forecasting
- Hybrid Deep Learning (LSTM + CNN)
- Transformer-based NLP (FinBERT)
- Feature Engineering for Financial Data
- Explainable AI (XAI)
- Cross-market analysis
